# مهارة نظام تصميم تايلويند فائق الجمال (Tailwind CSS Design System)

هذه المهارة تضمن كتابة كلاسات وتنسيقات تايلويند احترافية، نظيفة، وغير مكررة لإنشاء صفحات سريعة التحميل وخفيفة الوزن.

## 1. لوحة الألوان المعتمدة (Color Palette)
- **الخلفيات (Backgrounds)**:
  - الفاتح: `bg-slate-50` للسطح العام، و `bg-white` للبطاقات والحاويات.
  - الداكن: `bg-slate-950` للسطح، و `bg-slate-900` للبطاقات.
- **الألوان الأساسية (Primary & Accents)**:
  - الأزرق السماوي المائي (مناسب جداً لتطبيقات الاشتراكات والماء):
    - `sky-500` / `blue-600` للأزرار والروابط البارزة.
    - `sky-50` / `blue-50` للخلفيات الخفيفة للوسوم والأيقونات.
- **ألوان الحالات (Status Indicators)**:
  - الأخضر (النجاح / التحصيل): `emerald-500` / `bg-emerald-50` / `text-emerald-700`.
  - البرتقالي (الانتظار / الأقساط): `amber-500` / `bg-amber-50` / `text-amber-700`.
  - الأحمر (المتأخرات / التنبيهات): `rose-500` / `bg-rose-50` / `text-rose-700`.

## 2. المسافات والزوايا (Spacing & Radii)
- استخدام تباعدات متناسقة من مضاعفات 4 (`p-4`, `p-6`, `gap-4`, `gap-6`).
- زوايا عصرية ناعمة مستديرة:
  - البطاقات: `rounded-2xl` أو `rounded-xl`.
  - الأزرار والحقول: `rounded-lg` أو `rounded-xl`.
  - الوسوم الصغيرة: `rounded-full`.

## 3. التحسينات البصرية المتقدمة (Visual Enhancements)
- **الظلال الأنيقة**: `shadow-sm` للقوائم، و `shadow-md shadow-slate-200/50` للبطاقات البارزة.
- **الحدود المتناسقة**: `border border-slate-200/70` لتعريف حدود العناصر بدقة دون خشونة.
- **تأثيرات المرور**: `hover:bg-slate-50 hover:border-slate-300 transition-all duration-200`.
